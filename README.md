# Subtle Scents Bloom

Build a beautiful, premium, feminine e-commerce website for a handcrafted candle brand called “Subtle Scents”.

BRAND:
Subtle Scents 🕯️
Tagline:
“Thoughtfully crafted. Beautifully scented. Made to make every moment special.”

Brand personality:
Soft, elegant, warm, intimate, handcrafted, romantic, premium, calming and slightly luxurious.

The website should NOT feel like a generic Shopify template or a corporate candle store.

The feeling should be:
✨ “I want to live in this house.”
🕯️ Warm candlelight
🤍 Soft luxury
🌸 Self-care
🎁 Thoughtful gifting
🌿 Conscious living

DESIGN DIRECTION:

Create a sophisticated editorial-style aesthetic inspired by premium fragrance, skincare and lifestyle brands.

Use a warm neutral palette:
- Ivory / cream
- Warm beige
- Soft taupe
- Muted blush
- Very subtle brown
- Small amounts of charcoal for text

Avoid:
- Bright colors
- Neon
- Excessive gradients
- Generic purple/pink AI aesthetics
- Overly rounded cartoon-like UI
- Excessive glassmorphism
- Anything that makes the brand look cheap

Typography:
Use an elegant high-contrast serif font for major headings and a clean modern sans-serif for body text.

The typography should create a beautiful contrast between:
“luxury editorial” + “modern handmade brand”.

Use generous whitespace throughout the website.

The website should feel calm and expensive rather than crowded.

--------------------------------------------------
MOBILE EXPERIENCE
--------------------------------------------------

This is extremely important.

The website must be designed mobile-first.

On phones:
- Navigation becomes a clean hamburger menu
- Hero typography scales properly
- Images never overflow
- Product cards become 2-column or 1-column depending on screen width
- Buttons remain easy to tap
- Cart remains accessible
- No horizontal scrolling
- Animations remain smooth but lightweight

Test the layout at:
320px
375px
390px
430px
768px
1024px
1440px+

--------------------------------------------------
ANIMATIONS
--------------------------------------------------

Use subtle premium animations.

Examples:
- Smooth fade-ins
- Gentle image reveals
- Soft text movement
- Product image hover zoom
- Smooth page transitions
- Subtle floating candle glow
- Elegant scroll animations

Animations should feel like a luxury fragrance website.

DO NOT:
- Make everything bounce
- Use excessive parallax
- Add flashy transitions
- Slow down page loading
- Animate every element

Prioritize performance.

--------------------------------------------------
MICRO-INTERACTIONS
--------------------------------------------------

Add tasteful details:

- Heart animation when adding to wishlist

- Smooth Add to Cart feedback
- Button hover transitions
- Image hover effects
- Soft cursor interactions where appropriate
- Toast notification when a product is added

Example:
“Added to your little collection 🕯️”

--------------------------------------------------
TECHNICAL REQUIREMENTS
--------------------------------------------------

Build this as a real, production-quality website rather than a static mockup.

Use clean reusable components.

Keep product data separate from UI so products can easily be changed later.

Use semantic HTML.

Make the website accessible.

Optimize images.

Lazy-load images where appropriate.

Keep animations performant.

Make sure there are no console errors.

Make sure all buttons and navigation links work.

Do not use fake functionality that looks functional but does nothing.

If backend/payment functionality isn't configured yet, create the UI and structure it so real functionality can be connected later.

--------------------------------------------------
IMPORTANT BRAND RULE
--------------------------------------------------

The most important thing is the emotional experience.

When someone opens the website, they should immediately feel:

“Subtle Scents feels handmade, beautiful, calming and premium.”

It should feel like a brand someone would discover on Instagram and immediately want to explore.

Think:
Aesop × Diptyque × Pinterest-inspired handmade luxury

BUT DO NOT COPY any existing brand's website, branding, layout or assets.

Create an original identity specifically for Subtle Scents.

The final result should feel:
warm + feminine + premium + handcrafted + minimal + romantic + trustworthy.

Make the website beautiful enough that it could genuinely be used as the official website for the brand.
